# Covers Sandbox — модули и проверка

## Автономный запуск

Основной файл: `../Sandbox_Styles_v8_WORKING.html`. Откройте его в Chrome/Edge. Проект браузерный, не требует Electron, сервера или внешних библиотек. Если шаблонной библиотеки нет, используйте **Вставить JSON** или **Импорт .js**. Перед добавлением открывается шаг назначения программного стиля для каждого входящего `visualStyle`; существующие темы можно выбрать для слияния либо сделать отдельную именованную версию.

## Разделение данных

- `templateGroup` — категория шаблона.
- `visualStyle` — программная тема для библиотеки и renderer.
- `editorStyleId` и `v5Bindings` — отдельный редакторский набор и его текстовые привязки.

В чистом запуске редакторские стили не создаются по умолчанию; список может быть пустым, и из него можно удалить все наборы. Это не удаляет категории/шаблоны и не отключает программные темы renderer.

## Адаптация

`adaptation.js` использует Range API для измерения фактической высоты живого текста. При последовательной раскладке сохраняется отдельный исходный gap каждой пары текстовых блоков; общий gap не назначается. Если исходная пара уже пересекается, применяется минимальный страховочный промежуток. Shapes/images не двигаются, размер шрифта не меняется. Ручной диапазон ограничен первым и последним выделенными текстами в визуальном порядке; промежуточные тексты входят, блоки выше и ниже не измеряются, не меняются и не сдвигаются. Auto всегда работает по всему шаблону и использует debounce с delay из UI (400 мс по умолчанию). Переключатели Auto/Диапазон — обычные checkbox; изменения настроек обновляют только их состояние/status и не вызывают полный render. В `test-fixtures/covers_unique_templates_4_standardized.js` добавлена библиотека для регрессионного теста конкретного примера.

Ручные тесты чистого planner без браузера:

```sh
node style-v8/adaptation.test.js
```

Они проверяют одинаковую колонку, неподвижность соседней колонки и shapes/images, исправление перекрытий в приложенном fixture `test-fixtures/covers_unique_templates_4_standardized.js`, переключатель диапазона, границы выбранного диапазона, EPS и нулевое измерение.

## Пресеты

Ряды ролей раскрыты постоянно. В деталях пресета отображаются только вес и цвет. В категории её варианты нумеруются отдельно. «Все категории» показывает упорядоченный список уникальных фактических сочетаний цвета и веса; один номер объединяет эквивалентные варианты, а редактирование общего номера применяет значения ко всем его исходным категориям.

## Карта и выделение

Кнопка-фильтр включает показ только отмеченных шаблонов. Кнопка Split показывает пару только при ровно двух отмеченных шаблонах; при другом количестве показывает подсказку выбора. В режиме «Один» и в Split текстовые блоки множественно выделяются Shift+кликом. При редактировании стилей пустой клик не сбрасывает это выделение; в обычном редакторе рамка multi-select синяя. В обычной Карте выделение шаблонов не меняет семантику.

## Изображения и измерительный overlay

`image-normalization.js` экспортирует переиспользуемую `normalizeTemplateImages(template)`: меняет только image-блоки (границы контейнера/full-bleed и `imageTransform`). Template Manager предлагает нормализацию текущего или отмеченных шаблонов; перед JS-экспортом нормализуются только экспортные копии. В Style Editor переключатели расстояний и типографики рисуют отдельный SVG overlay поверх stage/Map preview; в `LIB` он не сохраняется. При изменении выделения в обычной Карте обновляются классы существующих карточек; selected-only/Split согласуют состав карты дифференциально, сохраняя DOM и наблюдатели неизменённых карточек.

## Сборка и тесты

```sh
python style-v8/build.py
node style-v8/adaptation.test.js
node style-v8/engine.test.js
node style-v8/image-normalization.test.js
```

Browser тесты `browser-smoke.js`, `interaction.test.js`, `v8-features.test.js`, `individual-variants.test.js`, `migration.test.js`, `archive.test.js` требуют Playwright и Chromium. Тесты на полную библиотеку также требуют `uploads/portfolio_template_library_all_96.js`, который не включён в публичный проект. В текущем окружении выполнены сборка, синтаксические проверки модулей и inline-скриптов, локальный smoke движка и synthetic planner tests; браузерный проход недоступен.
